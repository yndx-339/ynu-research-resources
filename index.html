推荐检索路径

1定题与查全：两路合用

知网 kns8s 主题检索（近五年 / CSSCI + 北大核心 / 学术期刊 / 相关性排序）＋ CNKI AI 增强检索（语义）。实测两路题录零重合：主题检索兜住专名本体，语义检索打通交叉议题，缺一路即漏检。

2理论话语与政策口径

中国共产党思想理论资源数据库、人大复印报刊资料全文数据库、国家哲学社会科学学术期刊数据库、皮书数据库，以及《铸牢中华民族共同体意识数据库》专题库。

3专著与史料纵深

读秀做书内段落定位（图像型，截图识别）、汇雅书城读整本电子书；中国数字方志库、中国基本古籍库、晚清民国期刊全文库补史料。

4边疆与周边专题

古代边疆研究信息服务平台、一带一路数据库、东南亚 & 缅甸研究专题电子图书、台湾联合百科数据库。

5外文与引证核验

Web of Science / Scopus 补外文与引证，ScienceDirect / Springer / Nature / Wiley / IEEE 取全文；CSSCI、中国引文数据库、JCR、ESI 核来源期刊与影响力。

6题录导出与管理

知网导出 GB/T 7714 题录，EndNote / NoteExpress 管理；投 CSSCI 前用 CSSCI 来源期刊目录复核。

使用须知

  • 全部机构授权绑定云大校园网出口 IP；断网时先恢复校园网连接，否则所有 IP 直通资源立即失效。
  • 校外走代理 https://libresource.ynu.yitlink.com:8081/go?url=<目标URL>；读秀可在校内 IP 办「个人认证」后校外使用。
  • 单轮全文下载 ≤10–15 篇，不写批量爬取脚本——知网按 IP 监控，封学校授权 IP 代价极大。
  • CNKI AI 提交知识问答 / 辅助创作会在账号留新记录，须先征得同意；题录提取为只读。
  • 办事大厅与校内业务系统只做只读查看，不代登录、不代提交、不采集待办与消息明细。
  • 判断某库订没订，以图书馆数据库导航清单为准；出版社首页被 cookie 弹窗遮挡时不显示机构标识，不代表无权限。
  • 清单会变动（尤其试用库），隔段时间重跑 lib-nav-probe.mjs 更新。
