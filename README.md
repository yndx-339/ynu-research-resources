# 云南大学图书馆电子资源 · 科研检索集合

把云南大学图书馆「数据库导航」里的 **197 个数据库 / 平台**整理成一份可筛选、可搜索的清单，为每条资源标注主题标签、检索用途与推荐度，并保留「中华民族共同体意识 / 边疆民族地区治理」方向的专题检索入口。

**在线页面（GitHub Pages）**：<https://yndx-339.github.io/ynu-research-resources/>

页面支持按分类、语种、主题标签、快捷筛选（★3 推荐 / 试用 / 已实测）和关键词组合过滤；同一份数据也提供 CSV，便于导入 Excel 或文献管理工具。

## 数据概况

| 维度 | 数量 |
| --- | --- |
| 总条目 | 197 |
| 中文数据库 | 91 |
| 外文数据库 | 81 |
| 试用数据库 | 21 |
| 实测补充 | 4 |
| 语种：中文 / 中文为主 / 外文 | 95 / 21 / 81 |
| 标注「IP 直通（已实测）」 | 13 |

主题标签共 13 个：边疆治理·周边研究、法学·制度、工具·学习、共同体意识·民族理论、开放获取、理工农医、期刊·全文、史料·古籍、数据·统计、图书·专著、学位论文、引文·评价、政策·理论话语。每条最多挂 3 个标签，未命中规则的默认归入「期刊·全文」。

## 已知局限（使用前请读）

- **直达链接覆盖率低**：197 条中只有 **14 条（约 7%）**填了直达 URL。其余 183 条卡片上的按钮跳转到图书馆数据库导航清单页，需要按库名再找一次入口。「直达入口」目前只是部分实现，不是全部。
- **试用库有时效**：21 条试用数据库的开通状态随学校采购变化，可能已到期或转正，以图书馆清单页实时状态为准。
- **备注不全**：仅 16 条带备注（访问限制、并发数等提示），其余条目未逐一核实使用细则。
- **数据是快照**：采集自图书馆导航页（lib.ynu.edu.cn），最近一次更新为 2026 年 11 月中旬。图书馆增删数据库后本清单不会自动同步。

## 访问方式

1. **校园网内**：多数库按 IP 直通，打开链接即可用（13 条已实测确认）。
2. **校外**：走图书馆远程访问代理，格式为
   `https://libresource.ynu.yitlink.com:8081/go?url=<目标URL>`
   需图书馆账号认证；部分库另有限制，见各条备注或图书馆说明。
3. **找入口**：没有直达链接的条目，从卡片按钮进入图书馆数据库导航清单页，按库名检索。

## 仓库文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 发布页面（GitHub Pages 入口），内嵌全部 197 条数据与筛选逻辑，单文件、无外部依赖 |
| `科研资源库集合.csv` | 同一份数据的表格版，12 列：序号、库名/平台、来源、分类、语种、状态、主题标签、检索用途、推荐度、访问方式、直达链接、备注 |
| `ynu-db-list.csv` | 从图书馆导航页抽取的分类库名清单（193 条，UTF-8 BOM），是构建的输入 |
| `lib-nav-probe.mjs` | 采集脚本：通过本机 Edge 调试端口（CDP，默认 9333）只读抓取图书馆导航 5 个页面，解码跳转目标，产出 `lib-db-result.json`（中间产物，未入库） |
| `make-db-csv.mjs` | 从 `lib-db-result.json` 抽取分类库名，生成 `ynu-db-list.csv` |
| `build-collection.mjs` | 读入库名清单，按规则打主题标签 / 检索用途 / 推荐度，生成 `科研资源库集合.html` 与 `.csv` |

## 重新生成流程

```text
lib-nav-probe.mjs ──> lib-db-result.json（本地中间产物）
        │
make-db-csv.mjs ──> ynu-db-list.csv
        │
build-collection.mjs ──> 科研资源库集合.html + 科研资源库集合.csv
```

发布时把生成的 `科研资源库集合.html` 更名为 `index.html` 提交即可（Pages 默认服务 `index.html`）。采集脚本需要在能访问校园网、且 Edge 已开调试端口的机器上运行；构建脚本只需 Node.js。
